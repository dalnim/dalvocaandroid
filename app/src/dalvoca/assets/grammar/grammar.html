Be 동사

  • 나는 아프다.
  • 나는 행복하다.
  • 나는 학교에 간다.

문장을 만들 때, 끝에 "~이다."라고 끝나죠?

영어로 "~이다. ~있다." 뜻을 가진 친구들을 be 동사 라고 해요.

일반동사

일반동사는 주어의 동작이나 상태를 표현해주는 동사에요.

예를 들면,

나는 아파요 -> I'm sick

주어 =나 (I), 일반 동사 = 아프다 (sick)

나는 학교에 가요 -> I go to school

주어 =나 (I), 일반 동사= 가다 (go)

근데 주어는 내가 될 수도 있고 다른 사람도 될 수 있죠?

일반동사는 주어 뿐만 아니라 시제에 따라서도 변해요.

시제란 현재, 과거, 미래를 말해요.

예를 들면,

(현재) 나는 학생이다 -> I am a student

(과거) 나는 학생이었다 -> I was a student

(미래) 나는 학생일 것이다 -> I will be a student

"이다 (be 동사)" 가 현재, 과거, 미래에 따라 모습이 달라졌죠?

(현재) am / (과거) was / 미래 (will be)

이렇듯, be 동사뿐만 아니라 일반동사는 시제에 따라 모습이 변해요.

현재일 때는 일반동사 그대로 모습이에요.

과거일 때는 일반동사 뒤에 -d나 -ed를 붙여줘요.

미래일 때는 일반동사 앞에 will을 붙여줘요.

단수와 복수

단수와 복수란 무엇일까요?

단수=1개

복수= 2개 이상 여러개

예를 들면,

사과 1개 = 단수

사과 3개= 복수

1개를 여러개로 말하고 싶어요.

단수를 복수로 만들어줘야 하는데 어떻게 만들면 될까요?

첫번째, 단수 뒤에 -s를 붙여줘요

  • Pen (펜 한 개) -> Pens(펜 여러 개)
  • Apple (사과 한 개) ->Apples (사과 여러 개)
  • Dog (강아지 한 마리) ->Dogs (강아지 여러 마리)
  • Book (책 한 권) -> Books(책 여러 권)

예를 들면,

사과가 한 개 있어요 -> There is an apple

사과가 세 개 있어요 -> There are three apples

두번째, 단수가 s, ss, sh, ch, x, o로 끝나면 뒤에 -es를 붙여줘요

  • Bus (버스 한 대)->Buses (버스 여러 대)
  • Class (수업 한 개)-> Classes (수업 여러 개)
  • Box (박스 한 개) ->Boxes (박스 여러 개)
  • Potato (감자 한 개) -> Potatoes (감자 여러 개)

예를 들면,

박스 한 개 있어요? -> Do you have a box?

박스 여러개 있어요? -> Do you have several boxes?

세번째, 단수가 자음+y로 끝나면 y를 i로 바꾸고 -es를 붙여요

  • Baby (아기 한 명)->Babies (아기 여러 명)
  • Lady (여성 한 명) ->Ladies (여성 여러명)

예를 들면,

귀여운 아기가 한 명 있어요 -> There is a cute baby

귀여운 아기 6명이 있어요 -> There are six cute babies

네번째, 단수가 f, fe로 끝나는 경우, f, fe를 v로 고치고 -es를 붙여요

  • Wife (아내 한 명) ->Wives (아내 여러 명)
  • Leaf (나뭇잎 한 개)-> Leaves (나뭇잎 여러 개)
  • Knif (칼 한 개) ->Knives (칼 여러 개)

예를 들면,

저는 떨어지는 낙엽 하나를 보고 있어요 -> I'm watching a falling leaf

저는 떨어지는 낙엽들을 보고 있어요 -> I'm watching falling leaves

단수에서 복수로 변할 때, 모습이 바뀌죠?

그런데 단수일 때도, 복수일 때도 모습이 똑같은 친구들이 있어요.

  1. Fish (물고기 한 마리)->Fish (물고기 여러 마리)
  2. Sheep (양 한 마리)->Sheep (양 여러 마리)
  3. Deer (사슴 한 마리)->Deer (사슴 여러 마리)

연못에 물고기 한 마리가 있다 -> There is a fish in the pond

연못에 물고기가 많이 있다 -> There are many fish in the pond

이번에는 반대로 단수가 없고 항상 복수만 있는 친구들이 있어요.

왜냐하면 이 친구들은 여러개가 합쳐져서 1개가 되거든요.

  1. Clothes 옷
  2. Jeans 청바지
  3. Shorts 반바지
  4. Scissors 가위
  5. Trousers 긴 바지
  6. Glasses 안경

예를 들면,

저는 새로운 안경을 쓰고 있어요 -> I'm wearing new glasses
